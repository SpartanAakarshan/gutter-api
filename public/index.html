How it works

Three steps. Zero friction.

01
Install Gutter from the Chrome Web Store and open the extension options. Sign in with Google and paste your Gemini API key — available free from Google AI Studio.
02
Alt+Click any heading, bold text, or selected passage on any webpage. A tooltip appears inline — no new tab, no context switch.
03
Read two sentences. What it is. Why it matters. The tooltip closes. You're back where you were.
Security & Trust

Your API key is yours.

Gutter uses a bring-your-own-key model. You connect your own Gemini API key — we never have access to your account or quota. Here is exactly what happens to your key.

Encryption at rest
Your API key is encrypted with AES-256-GCM before being written to the database. The raw key never touches storage.
